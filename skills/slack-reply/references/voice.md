# My voice

Edit freely. Everything here overrides the skill's default rules.

## Who I'm usually replying to

Data scientists on a fraud ML team asking platform questions (KFP v2 pipelines, PySpark, Snowflake, Artifactory packages). Most replies are either an answer, a "here's where it stands", or a "I'll pick this up — need X from you first".

## Rules

- Lead with the answer or the status, then the why.
- No exclamation points.
- "Sounds good", not "Sounds great". "Yep" is fine.
- If I'm asking them for something, make the ask a single clear sentence, ideally the last line.
- Don't soften a "no" into a maybe. State it, then offer the alternative if the draft had one.
- Keep my hedges when they're real ("should", "I think") — remove them when they're just filler.

## Avoid

- circle back, touch base, bandwidth, leverage, align on, going forward
- "just" as a softener ("just wondering", "just checking")
- Apologizing for delays unless the draft does

## Example replies that sound like me

Replace these with real ones you've sent — three or four is plenty.

> Yep, the backfill's rerunning now. Should land in `fraud_features_v2` by 3ish. I'll ping you if it slips.

> Not on the platform yet — that package isn't in Artifactory. If you send me the version you need I'll get it added, usually takes a day.

> The component's failing on the Spark config, not your code. Bump `spark.executor.memory` to 8g in the pipeline params and rerun. If it still dies, send me the run ID.
